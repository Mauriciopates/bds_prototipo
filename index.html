Viva: checkout com a marca BDS

A BDS já trabalha com a Viva. A mesma conta passa a receber os pagamentos do site através do Smart Checkout, personalizado com o logótipo e a cor da marca.

O que a Viva permite fazer no site

  • Pré-autorização: o valor fica cativo e só é cobrado depois de o cliente aprovar a arte.
  • Link de pagamento: cada orçamento gera um link que se envia por WhatsApp ou email, e o cliente paga sem criar conta.
  • Loja física e site juntos: as vendas do terminal e do site aparecem no mesmo painel Viva.
  • Descrição clara: o cliente vê "BDS · Encomenda BDS-1042 · 25 polos bordados".
  • Métodos certos para Portugal: MB WAY, Multibanco, cartão, Apple Pay e Google Pay no mesmo checkout.

Excerto do script de sincronização (Python)

import requests, mysql.connector
from decimal import Decimal

MARGEM = Decimal("1.35")          # preço de venda = custo × 1,35

def sync_fornecedor(db, url, token):
    artigos = requests.get(url, headers={"Authorization": f"Bearer {token}"}, timeout=30).json()
    cur = db.cursor()
    for a in artigos:
        preco = (Decimal(str(a["price"])) * MARGEM).quantize(Decimal("0.01"))
        cur.execute("""
            INSERT INTO produtos (sku, nome, categoria, custo, preco, stock)
            VALUES (%s, %s, %s, %s, %s, %s)
            ON DUPLICATE KEY UPDATE custo=VALUES(custo), preco=VALUES(preco), stock=VALUES(stock)
        """, (a["sku"], a["name"], a["category"], a["price"], preco, a["stock"]))
    db.commit()
    publicar_na_loja(cur)                # PUT /wp-json/wc/v3/products/batch

# crontab: todos os dias às 06:00
# 0 6 * * *  /usr/bin/python3 /opt/bds/sync.py
